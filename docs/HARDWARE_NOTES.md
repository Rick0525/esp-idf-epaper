# 硬件研究笔记

记录 0154T8 / IL0373 屏的物理特性、未跑过但值得探索的实验、字体方案选型等"知道但暂不动手"的内容。

## 屏体溯源（已验证：WeiFeng WF0154T8）

本项目用一块 WeiFeng 1.54" 黑白屏验证驱动一致性。屏面板丝印：

```
WF0154T8PCZ17230H
U51Q0505075138-U011
Brand: WEIFENG    Description
WUXI VISION PEAK TECHNOLOGY: EPD
```

解读：

- **品牌**：WEIFENG（威锋）；厂家：WUXI VISION PEAK TECHNOLOGY（无锡威峰科技）
- **型号**：`WF0154T8PCZ17230H`
  - `WF` = WeiFeng
  - `0154` = 1.54 英寸
  - `T8` = **行业通用规格代号**：1.54" 黑白电子纸"B 规格"——8 pin 接线、152×152 分辨率、IL0373 控制器
  - `PCZ17230H` = 厂家批次/产品编码
- 第二行 `U51Q...-U011` 是流水号/生产批号

### 关键判断

**`0154T8` 是行业标准接线规格，不是 Good Display 专属**。WeiFeng、Good Display 等代工厂的 1.54" 黑白屏都按这个规格做，**协议层完全兼容**——同接线、同 IL0373 命令集、同 152×152、同全刷时序。

### 实测一致性证据

用 GxEPD2_154_T8（GDEW0154T8 + IL0373）的命令集和 5 张全刷 LUT 驱动 WeiFeng WF0154T8 验证：

- BUSY 极性 LOW=忙 / HIGH=空闲 → 与 IL0373 一致
- DisplayRefresh 耗时实测 1550ms ↔ GxEPD2 头文件标 `full_refresh_time = 1600ms`
- PowerOn 耗时 ~40ms ↔ GxEPD2 标 `power_on_time = 60ms`
- 152×152 RAM 寻址边界、外圈白边特性也一致

驱动代码无需任何修改。涉及屏型号的描述统称"0154T8 兼容屏"或"WeiFeng WF0154T8（与 GDEW0154T8 同规格）"更准确。

### 实践提示

- 屏面板印的型号 ≠ 控制器型号。`0154T8` / `0154Z08` / `0154D67` 这类后缀是规格代号，要查控制器要么看 GxEPD2 类对应 `.cpp` 顶部注释，要么看 IC 上的丝印（IL0373 / SSD1681 / IL3897 等）
- 换货/维修时只要找标 `0154T8` 的 1.54" 黑白屏即可，品牌不重要

## 152×152 有效区与外圈白边

### 现象

黑/白循环全刷诊断观察：

- **瞬时黑相**：刷新中间相位，黑色覆盖整个屏物理可视区
- **稳定全黑**：四周各少一条白边（约几像素，对称分布）
- **稳定全白**：白屏满屏看不出差别

结论：屏物理像素阵列大于 152×152，但 `RESOLUTION (0x61)` 设定的 152×152 才是真正"被 RAM 寻址 + LUT 持续驱动"的有效像素区。外圈像素在黑相时被电压扫到、稳定后没人维持，回到白色。**这一圈白边是屏物理特性，不是驱动 bug**，与 GxEPD2_154_T8 的实现一致（`WIDTH = WIDTH_VISIBLE = HEIGHT = 152`）。

### RESOLUTION (0x61) 的设置位置

`components/epaper_il0373_154t8/epaper_154.c::il0373_init_display()`：

```c
const uint8_t p[3] = { EPD_W, (EPD_H >> 8) & 0xFF, EPD_H & 0xFF };
cmd_data(IL0373_RESOLUTION_SETTING, p, sizeof(p));   // 0x61: W, H_hi, H_lo
```

W 用 1 字节、H 用 2 字节大端。三处必须同步：`EPD_W/EPD_H` 宏、帧缓冲 `s_framebuf` 大小、0x61 参数（目前由宏推出，自动同步）。

### 能改吗？

**理论上 IL0373 datasheet 的最大分辨率是 160×296**——GDEW0154T8 借了同一颗 IC，但物理像素阵列只挖到大约 ~160×160 的方屏。所以 W 至多到 160，H 也是。

**风险**：

1. **帧缓冲必须等比扩大**：W 必须是 8 的倍数（按字节寻址）。160×160 → 3200 字节
2. **LUT 是按 152×152 时序调的**——5 张 LUT 直接复制自 `GxEPD2_154_T8.cpp`，扩大后 LUT 不一定能正确驱动新增那一圈像素，最坏花屏/残影/不全黑
3. **GxEPD2 作者多年用这屏钉死 152**——大概率试过更大不行才回到 152，但作者未留记录

### 待跑实验：扩到 160×160

把 `EPD_W = EPD_H = 160`（8 的倍数 + 在 IL0373 上限内），看稳定全黑能否扩到接近物理边：

- 如果可以 → 比 GxEPD2 多榨出一圈像素
- 如果不行 → 回 152，这条路封死

操作：

1. 切临时分支 `experiment/resolution-160`
2. `epaper_154.h` 改 `EPD_W = EPD_H = 160`，重 build
3. 烧录全黑/全白循环全刷诊断版（直接修改 main.c 反复 `clear(0/0xFF) + display_full`）
4. 观察稳定全黑边界 vs 152 时的边界
5. 不论结果，提交结果观察 → 决定 merge 或 revert 整个分支

成本：估计 30 分钟，主要是观察。

## 字体方案选型

当前默认字体：8×8 复古点阵（`font8x8_basic.h`，dhepper 公共域，128 个 ASCII 字符 × 8×8 像素 = 1KB，极小）+ FreeSansBold9pt7b（GFX 比例字体，~2KB）。

要换字体或加新字号，参考下面分场景的备选库。

### 按场景对照

#### 纯英文/数字（小屏、低 RAM）

| 字体库 | 形态 | 大小估计 | 备注 |
|---|---|---|---|
| **U8g2 字体** | 位图，几百种字号字形 | 几百字节~几 KB/字体 | 嵌入式生态最丰富。例：`u8g2_font_6x10_tf`、`u8g2_font_helvB12_tr`、`u8g2_font_ncenB14_tr`。需自带渲染器或转 GFX 格式 |
| **Adafruit_GFX 字体** | 位图，FreeMono/Sans/Serif × Bold/Italic × 9/12/18/24pt | 2-10 KB/字体 | 本驱动直接支持。复制 `.h` 到 `fonts/`、改一行 include 即可 |
| **8×8 / 8×16 复古点阵** | 位图，固定方阵 | <2 KB | DOS/IBM 味，极简 UI 首选 |

#### 大数字（时钟/温度计/读数）

| 字体库 | 备注 |
|---|---|
| **DSEG**（公共域七段码） | `DSEG7-Classic`、`DSEG14-Classic`，转 1bit 点阵后特别合墨水屏的"工业感" |
| **U8g2 logisoso 系列** | `u8g2_font_logisoso92_tn` 等，单数字最大 92 像素高，时钟主屏标配 |
| **U8g2 inb 系列** | `u8g2_font_inb24_mn` 等等宽数字，可读性强 |

#### 中文

| 字体库 | 形态 | 大小估计 | 备注 |
|---|---|---|---|
| **U8g2 wqy 系列**（文泉驿） | `u8g2_font_wqy12_t_gb2312`、`wqy16` | 全 GB2312 ~200 KB；子集裁剪后 5-20 KB | 嵌入式中文最常见 |
| **自制裁剪字体** | 用 Pillow + 一个 TTF（思源黑体/苹方）按字符集生成 1bit 点阵 → C 数组 | 按字符数线性 | 只收屏上要显示的几十个字，ROM 占用极低 |
| **LVGL 字体转换** (`lv_font_conv`) | 任意 TTF → LVGL 字体 | 灵活 | 支持子集化、可选抗锯齿（多 bit） |

#### 图形 UI（带 GUI 框架）

- **LVGL** 自带字体系统（Montserrat 系列 + 符号字体）。1bpp 模式直接出 0/1 像素，墨水屏适用

#### 图标

- **Font Awesome 1bit 化** 或 **LVGL Symbol**：用字体存图标比存 PNG 省事
- 时钟/天气类应用常做法：自己挑几十个 16×16 / 24×24 图标做成"图标字体"

### 实践建议（针对 152×152 1bit 屏）

- **纯英文 + 数字静态显示**：U8g2 一两种字号搞定，比如正文 `u8g2_font_helvR08_tr`（小字号正文）+ 大数字 `logisoso30_tn`，ROM <10 KB
- **直接用 GFX 格式**：Adafruit_GFX 仓库任意 `.h` 复制进 `fonts/`，本驱动原生支持
- **要中文**：默认 U8g2 wqy12 子集裁剪；如果只显示几个固定字（"温度"、"湿度"等），自己用 Pillow 生成更省
- **做时钟/天气这类"漂亮主屏"**：DSEG 大数字 + U8g2 helv 中字号 + 自制图标字体——这一类项目的"经典三件套"

### 墨水屏字体的工程注意

- **避免太细的笔画**（100 weight 等 thin 字体）：墨水屏刷新粒度会吃掉细线条，看起来断断续续。优先**粗体/中等粗细**
- 1bit 输出**没有抗锯齿**：曲线和斜线会有"楼梯感"，所以选字体时挑笔画方正的（点阵字体本来就是这种风格）
- **字号选择**：在 152×152 屏上，正文 ≥ 8 像素高、标题 ≥ 16 像素高、主显数字 ≥ 30 像素高，这是远 1m 看清的下限
- **矢量字体在小字号下锯齿明显**：FreeSans/FreeSerif 这类源自 TTF 经 fontconvert 栅格化的字体，9pt（~13px 高）下圆角和斜线像素不够易楼梯化。要小字号好看用专为 1bit 设计的位图字体（U8g2 helvB10 / inb 系列）或加大字号
